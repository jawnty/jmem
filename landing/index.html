How it works

solid = context flows in. dashed = new decisions write back after each session.
01

Connect your sources. Claude Code, Codex, Gmail, Calendar, and your Granola notes. Your code history and project docs come along too.

02

It builds one brain. On SessionStart and Stop hooks, Carryover indexes new context into SQLite (memory_items, tagged and evidenced). Self-host it, or let us run it on an open model so your data never goes to a third-party LLM.

03

It injects the relevant slice. On UserPromptSubmit, before the agent's first reply, a small source-labeled packet is injected. No pasting, no re-explaining.
